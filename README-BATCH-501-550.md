# Avorqin Batch 501–550

This package adds 50 Electrical & Electronics tools selected from Avorqin's Google Search Console query/page signals.

## Includes
- 50 SEO-friendly tool routes
- Shared Electrical calculator UI
- Pure calculation engine
- Tool registry data
- PowerShell installer + verifier
- Homepage count wording change from exact count to `500+` until Avorqin reaches 1,000 tools

## Install
1. Extract this ZIP.
2. Copy everything inside into the root of the Avorqin repository.
3. Run:
   `powershell -ExecutionPolicy Bypass -File .\scripts\install-batch-501-550.ps1`
4. Verify:
   `powershell -ExecutionPolicy Bypass -File .\scripts\verify-batch-501-550.ps1`
5. Commit/push and let Cloudflare run the production build.

## Electrical safety
Wire, fuse, breaker, transformer, generator, and motor results are planning estimates. Real installations must follow equipment specifications, ampacity limits, local electrical codes, and qualified professional guidance.
